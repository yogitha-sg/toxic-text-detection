# Toxic Text Detection

## Description

This project detects potentially toxic or offensive language in text messages.

## Technologies Used

- Python
- Natural Language Processing
- Regular Expressions
- Text Classification

## How It Works

1. The user enters a text message.
2. The text is converted to lowercase.
3. The system checks for predefined toxic words.
4. A toxicity score is calculated.
5. The message is classified as Toxic or Non-Toxic.

## How to Run

No external libraries are required.

```bash
python toxic_text_detection.py
